# Invoice Extractor AI

This is an AI-powered invoice extraction tool that reads invoice images or PDFs and extracts key information like:

✅ Invoice Number  
✅ Date  
✅ Total Amount  
✅ Vendor Name  

It uses **OCR (Optical Character Recognition)** and AI to automatically read invoices.

## How to use

1. Upload an invoice image on the web interface
2. Click **Extract**
3. Get the extracted details in JSON

## Technologies Used

- FastAPI
- Tesseract OCR
- Python
